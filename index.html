☁️ Kết Nối Google Firebase Firestore (Miễn Phí 100%)
Mục đích: Kết nối Database Cloud để 100 nhân viên có thể dùng điện thoại đăng ký cơm đồng thời và dữ liệu tự động đồng bộ Realtime!
📋 4 Bước Kết Nối Nhanh:
  1. Truy cập console.firebase.google.com và đăng nhập tài khoản Google.
  2. Bấm Add project > Đặt tên (vd: DangKyCom).
  3. Tại menu bên trái: Chọn Build > Firestore Database > Bấm Create database (chọn vị trí asia-southeast1 - Singapore và chọn Start in test mode).
  4. Bấm vào biểu tượng Bánh răng (Project Settings) > Cuộn xuống chọn Web (</>) để lấy mã firebaseConfig.
📁 Dán cấu hình vào file:

Mở file js/firebase-config.js trong mã nguồn và dán mã config của bạn vào đó. Sau đó lưu lại và tải lại trang!

💬 Cấu Hình Nhắc Nhở Nhóm Zalo

Hệ thống sẽ tự động sao chép danh sách anh em chưa đăng ký và mở ngay nhóm Zalo để bạn dán (Ctrl + V) gửi vào nhóm trong tích tắc.

Dán link tham gia nhóm Zalo của đơn vị vào đây. Khi bấm "Gửi Tới Nhóm Zalo", hệ thống sẽ mở thẳng nhóm này để bạn dán tin nhắn. Nếu để trống, hệ thống sẽ mở chat.zalo.me.
Tùy chọn: Nhận thông báo tự động qua Zalo OA Webhook nếu đơn vị có thiết lập.
